# 用例：列表增删（状态更新）

在**一个文件**里实现并导出组件 `App`：

1. 一个字符串列表状态，初始 `["a", "b"]`。
2. `App` 渲染：
   - 一个 `<ul>`，每项一个 `<li>`，文本就是该项的值
   - 一个 `<p>`，显示当前项数，文本形如 `共 2 项`
   - 一个 `<input>`
   - 一个 `<button>`（文本 `添加`）：点击后把 `<input>` 里的文字追加到列表末尾，并清空输入框
   - 一个 `<button>`（文本 `删除末尾`）：点击后删掉最后一项
3. 每次操作后，列表与项数都必须立刻更新。

> 这份提示词对两个框架完全一样。请用**该框架的惯用写法**完成。
