# 用例：列表清空时的条件分支

在**一个文件**里实现并导出组件 `App`：

1. 一个字符串列表状态，初始 `["a", "b"]`。
2. `App` 渲染：
   - 列表**非空**时：一个 `<ul>`，每项一个 `<li>`，文本就是该项的值
   - 列表**为空**时：一个 `<p>`，文本是 `空`
   - 一个 `<button>`（文本 `删除一个`）：点击后删掉最后一项（列表已空时点击不做任何事）
3. 列表清空之后，`<ul>` 必须**从 DOM 里消失**（不是用 CSS 隐藏），同时 `<p>空</p>` 出现。

> 这份提示词对两个框架完全一样。请用**该框架的惯用写法**完成。
