# 用例：异步加载与重新加载

在**一个文件**里实现并导出组件 `App`：

1. 用一个返回 Promise 的函数模拟请求：约 10ms 后 resolve 出字符串 `数据N`，
   其中 `N` 是**第几次请求**（第 1 次得到 `数据1`，第 2 次 `数据2`，依此类推）。
2. `App` 首次渲染时就发起第一次请求，并渲染：
   - 请求进行中：一个 `<p>`，文本是 `加载中`
   - 请求完成后：一个 `<p>`，文本就是拿到的数据
   - 一个 `<button>`（文本 `重新加载`）：点击后发起**新的一次请求**，界面再走一遍「加载中 → 数据」

> 这份提示词对两个框架完全一样。请用**该框架的惯用写法**完成。
